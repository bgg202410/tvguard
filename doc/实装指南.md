## 第一步：装 APK

> 本说明是基于 2016 年的 TCL 电视，不保证其他电视有效

---

### 路线 A：U 盘（最稳）

1. U 盘格式化成 FAT32，把 `app-debug.apk` 拷到根目录
2. 插到电视 USB 口（蓝色 USB 3.0 口识别率最高）
3. 电视上打开文件管理器进行安装
4. 找到 APK 点击安装
5. 如果提示"禁止安装"：设置 → 系统/安全 → **允许安装未知来源应用**，打开；部分固件还要在「账户与安全」里关掉「安装防护」

### 路线 B：ADB（推荐）

开 ADB 的方法：

1. 设置 → **本机信息**（有的版本叫"关于"/"系统信息"）
2. 焦点停在这个页面上，**快速按遥控器：上 下 左 右**（部分固件是"上上下下左右左右"）
3. 会弹出一个隐藏菜单，里面找 **ADB 调试 / 网络调试**，打开
4. 记下电视的 IP（设置 → 网络 → 当前连接）

电脑上：

```bash
adb connect 192.168.x.x:5555
adb install -r app-debug.apk
```

连接被拒的话，先在电视上确认 ADB 开关是开的，再试 `adb kill-server` 后重连。

### 路线 C：多屏互动

TCL 自带「多屏互动」，部分机型支持从手机推 APK 到电视安装。入口在应用列表里，能不能用看固件版本。

---

## 第二步：设成默认桌面（部分电视无效）

装完先别急着按主页，按这个顺序试：

**1. 系统设置里找**
设置 → 通用/系统 → **桌面**（或「主屏幕」「默认应用」）→ 选「守时桌面」

**2. 按主页键看反应**

- 弹了"使用哪个应用"→ 选守时桌面 + **始终** → 成功
- 直接回原厂桌面，没问 → 进第 3 步

**3. 用 ADB 禁掉原厂桌面**

先确认原厂桌面包名（诊断页"当前默认桌面"那一行会显示）：

```bash
adb shell pm disable-user --user 0 com.ktcp.launcher
```

> 危险操作。禁用前务必确认包名是对的，禁错了会导致开机没有桌面。恢复用：
> `adb shell pm enable com.ktcp.launcher`

禁完重启，系统只剩守时桌面一个 HOME 候选，主页键就归你了。

**4. 还是被抢回去？**

有些固件有"桌面守护"式机制，会在待机唤醒后重置。这时候需要：
- 设置 → 应用 → 找到守时桌面 → 电池/后台 → **允许后台运行**、**加入白名单**
- 关掉系统的「睡眠清理」「自动清理后台」

这一步能不能成，直接决定产品在电视上能不能用。

---

## 第三步：开权限，看能不能拿到强管控

装好后：桌面最右边「家长设置」→ 设 4 位密码 → 进入设置页。

要开两个权限：

| 权限 | 作用 | 没开会的后果 |
| --- | --- | --- |
| 悬浮窗（显示在其他应用上层） | 决定能不能在看视频中途弹题 | 降级为弱管控，只在回桌面时拦 |
| 使用情况访问 | 精确判断前台是哪个 App | 退回音频信号，静音看视频会漏计 |

入口大概位置：

- **悬浮窗**：设置 → 应用 → 特殊权限/高级 → 显示在其他应用上层。
- **使用情况**：设置 → 应用 → 特殊权限 → 使用情况访问。
---

## 第四步：看诊断页

家长设置页最下面「设备诊断」，这一屏把 P0 摸底要的东西全列出来了。**装完第一件事就是进这里截图。**

要确认的六项：

| 看哪一行 | 期望值 | 不对怎么办 |
| --- | --- | --- |
| 是我自己吗 | 「是，桌面身份已生效」 | 回第二步 |
| 悬浮窗权限 | 「已开启」 | 回第三步；固件没入口就只能弱管控 |
| 使用情况权限 | 「已开启」 | 同上 |
| 管控强度 | 「强：可盖顶弹题」 | 只有弱管控说明产品体验要打折 |
| 逻辑尺寸 | 记录这个数 | 不是 960×540 的话，布局可能要调 |
| 音频是否在播 | 播视频时「是」，暂停变「否」 | 一直「否」说明音频判定不准，得靠使用情况权限 |

「前台应用」那一行尤其重要——播着爱奇艺看它有没有正确显示 `com.tcl.videoplayer` 或 `com.qiyi.video` 之类的包名。显示"读不到（未授权）"就是使用情况权限没开成。
